## Shopi - E-Commerce Application
A simple e-commerce application built with React, React Router, Bootstrap, and Vite. This app allows users to browse products, view their account, place orders, and more.
 

## Features
User Authentication: Login and signup functionality with email and password.
Product Categories: Browse products by categories such as Clothes, Electronics, Furniture, and Toys.
Order Management: View past orders and detailed order information.
Responsive Navbar: A responsive navigation bar that allows users to navigate through different sections of the app.
Local Storage: User and order data are stored in localStorage for persistence.


## Technologies Used
React: JavaScript library for building user interfaces.
React Router: For routing and navigation between different pages.
Bootstrap: For styling and responsive design.
Vite: Fast build tool for modern web projects.
